# 使用与验证

## 使用

将完整 `recreate-motion-from-reference` 文件夹放入你的 Agent 支持的 Skill 目录，或直接把 `SKILL.md` 作为任务指导，并提供参考视频与输出要求。项目级安装方式和远端测试结果见仓库 README 与 VALIDATION.md；不会自动安装到你的环境。

仅使用单文件时，无需案例和脚本也能执行主流程；额外资源用于查历史、复用提示词和检查成片。

## 文件检查

依赖：Python 3.9+、可执行的 FFmpeg 与 ffprobe。脚本不联网、不修改输入视频，检查结果写标准输出。

```sh
python3 scripts/check_video.py ./output.mp4 --fps 60 --frames 900 --duration 15 > ./checks.json
```

以上数值只是本例；换成当前项目要求。不传 `--fps` 时不会强制恒定帧间隔；对于可变帧率视频，检查解码帧的 `pts_time` 是否存在且递增，不把 `best_effort_timestamp_time` 的推定结果当原始 PTS 证明。即使检查通过，也不能据此声称参考源从未漏帧。

脚本只检查第一个视频流和全部音频流。通过不代表视觉复刻成功、没有静音、音画同步或资产可公开。最终仍需看关键转场、全片正常速度播放和听音。异常结果返回退出码 1；输入或工具错误返回 2。
