# 可复用提示词

以下是从实际制作经验重新整理的提示词，不是本次执行的逐字聊天记录，也不是原作者的完整提示词。输入括号内材料即可使用；无需全套机械地逐条执行。

## 1. 分析参考

请分析这条参考视频：[附件或原作链接]。我的目标是：[复刻范围与用途]，输出：[尺寸、帧率、时长、文件格式]，特别在意：[验收重点]。先确认你能真实看到视频，并探测文件参数。按呈现时间记录构图、元素身份、真实停顿、速度变化、形变顺序、文字遮罩与音效；复杂转场从前稳态查到后稳态。把确定观察和估计分开，不要凭一个封面补全整条视频。给我可用于实现的事件表和最影响相似度的几项关系。

## 2. 实现连续骨架

按已确认事件表制作可编辑版本。先保证主要形状、节奏和跨场景对象连续，再补文字、光照和粒子。相关元素由共同状态驱动，不要各自跑独立动画；普通经过点不应假刹车，真实停顿要保留。单帧状态由时间和稳定输入决定，并能乱序渲染。采用：[已指定工具或可用路线]。若指定路线无法完成，报告实际阻塞和替代选择，不要把诊断预览说成指定框架成片。

## 3. 针对差异修正

对照原作与当前版本，优先检查：[时间段与问题]。请用“时间 → 原作行为 → 当前偏差 → 修改 → 复查结果”记录本轮工作。先修节奏、动作顺序和对象关联，再修字号、形状和质感。保留已经认可的部分。静态比较和连续播放分别检查；没有看过或听过的部分明确写出来。达到本轮目标后导出新版本，避免无边界地重做全片。

## 4. 交付与对比

导出后检查实际文件的尺寸、帧率、时长、帧数、完整解码、时间戳和音轨。原作放左、复刻放右，保留完整画幅并说明音轨来源。默认只做起点对齐，不改变任一边速度；若帧率不同，按时间对齐。交付 MP4、可编辑工程、带版本的验证摘要与剩余差异。公开分享前核对原片、音乐、字体和标识的使用权；只提供链接时也保留作者署名。
