# 案例：Daryl 15 秒动效的 R2 复刻

## 来源和历史提示词

原作者：Daryl Patigas（@darel023）。
- 原帖：https://x.com/darel023/status/2103424524297420829
- 当时使用的案例页：https://jasonzhu.ai/en/prompts/claude-opus-5-5/2103424524297420829

工程保留了一段 355 字符的公开提示词，其开头是：

> You're a world-class motion designer, and this is your 15-second résumé reel.

其余内容的中文概述：做一段自信、有动感的个人展示，首秒吸引注意，串联排版、形状、镜头和配色等手法，用有记忆点的画面收尾，节奏要有配乐剪辑的感觉。原文出处请查看原作/案例页，当前可见性未核实。

这是原作者公开的创作 brief，不是足以独自重现本例画面的完整执行指令。本次复刻同时使用了视频参考、逐段测量与代码修改。未找到可公开核对的逐字完整执行对话，因此本包不声称提供“原始完整提示词”，也不声称一次生成。`reusable-prompts.md` 是事后整理的新模板。

## 参考实际起了什么作用

- 参考文件实测 1280×720、60fps、15 秒、900 帧。画面 HUD 的“1920×1080”是设计文字，不能充当导出参数。
- 事件边界来自视频：缓动曲线 → 排版 → 界面 → 图表 → 立体方柱 → 粒子 → 收束 → 片尾。
- 观察红点沿曲线运动并随容器平移，再保留为字母点、开关主体和片尾句点，避免每个场景新建一个不相干的点。
- 排版采用字母级错峰与遮罩；通知先横向展开再加高；图表逐柱生长和变形；柱阵换成粒子时先保留原体积再卷成旋涡。
- 字体名称和比例结合原片注记与测量；3D 光照、粒子运动与模糊是独立算法近似，没有原作者源工程。

## 实际迭代

最初源检查发现曲线与红点位置脱节、文字遮罩与错峰不足、通知 spinner/check 残留、图表同时生长和片尾环退出不准。后续修正了共享状态、进度继承、逐柱形变、片尾时序；再调整开场菱形与文字穿插、粒子宽臂和花状收束。

最终源检查实际对看了 24 个关键帧。已有源码级检查还覆盖有限值和乱序渲染一致性；这些检查不能代替对最终视频的完整人工观看。粒子造型、颗粒分布、拖尾、环的锐度及少量文字相位仍有差异，未达到像素一致。

## 获认可的版本

本次认可的是 R2 源码经 Native Canvas（@napi-rs/canvas）逐帧绘制、FFmpeg 编码得到的版本，不是已核实的官方 Remotion 导出。

- 实际文件：1280×720、60fps、900 帧、15.000 秒，H.264 + AAC。
- 字节数：3,710,963。
- SHA-256：634b2c098f9da483c8046bd5786473a2c3740072c81fef4e89945165c48195ba。
- 已检查：完整解码、连续时间戳、关键阶段联系表与片尾。
- 未完成：制作侧正常速度全片连续观看与主观听音验证。用户对本次版本的认可与这些技术检查分开记录。
- 配乐改用 Kevin MacLeod 的《Enter the Party》，120→128 BPM 保调处理，加入 CC0 音效；并非原片音乐。

本例另制作了原片与复刻左右同步对比。公开仓库的 media/ 目录提供 R2 与对比视频，安装用 Skill 目录不含这些媒体。对比视频左原作、右 R2，完整保留两侧画幅，无重定时；只使用 R2 的一条配乐音轨，不叠加原片音轨。其实际尺寸为 1920×628，60fps、900 帧、15 秒。
